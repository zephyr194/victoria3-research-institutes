# 安装与游戏内验收

## 安装

选择对应游戏版本的一个 zip：

- `ri-research-institutes-1.13-experimental.zip`
- `ri-research-institutes-1.14-experimental.zip`

解压后将以下两项放入 **游戏用户数据目录** 下的 `mod/`，保持同级：

```text
Victoria 3/mod/
  ri_research_institutes.mod
  ri_research_institutes/
    descriptor.mod
    common/
    localization/
```

Windows 通常是 `Documents/Paradox Interactive/Victoria 3/mod/`；macOS 通常是 `~/Documents/Paradox Interactive/Victoria 3/mod/`。如果用户文档目录被同步或重定向，以本机 Paradox 启动器实际使用的用户数据目录为准。

在启动器添加本地 Mod，将 State Research Institutes 加入当前播放集并启用。两个目标包使用相同 Mod ID，不能同时安装；切换目标前替换同名目录。初次验收建议建立测试存档。

## 基础流程

1. 启动后查看日志中的“国家科研计划”。在建筑列表寻找“国家科研院所”，建造一级。
2. 确认院所能招聘 1,000 人的完整编制，招聘达到 50% 后筹建按钮可用。检查政府预算承担工资与纸张、工具成本，私人建设不可用。
3. 识字率至少 10%、黄金储备至少 £25,000 时，点击筹建。应立即扣 £25,000，下一次周更新额外扣 £1,000，并出现生产科技研发速度 +5%、行政力 -10 的修正。
4. 在科技树选择一项生产科技，比较专项修正生效前后研究速度。创新力上限继续按原版计算。院所满员时基础生产方式应贡献每级 0.4 创新力。
5. 在建筑面板切换“协作研究网络”：需要经验主义，岗位与物资需求改变，每满员等级创新力变为 0.8。

## 国家计划与断供

- 转向军事或社会：旧重点立即消失，下次周更新出现新领域修正；不能同时获得多领域专项。13 次周更新内不能再次转向。
- 到 26 个有效科研周、30% 识字率时升级 II；到 78 周、50% 识字率时升级 III。分别检查即时升级费和下周 £3,000 / £8,000 周费，以及 +10% / +20% 与行政力占用。
- 缩减一级：旧修正立即撤销，下周出现较低等级，经验周数保留。
- 暂停：立即移除专项及交流修正；后续不扣专项费。院所工资、物资与基础创新力仍继续，不能把“停拨”视为停用建筑。
- 把储备降至不足本周费用：周更新不扣专项费，修正消失，科研周数不增长；补足后下周自动恢复。
- 将所有本国院所的配员降到 50% 以下，或拆除全部院所：下次周更新停止专项。仅保留大学不能满足配员门槛。

## 科技交流

- 在和平、非闭关、20% 识字率且主计划正在拨款时立项。即时扣 £10,000，下周起每周另扣 £500，并出现科技传播 +25%、影响力 -25。
- 连续运行 26 个付费周，核对交流共支出 £23,000；主计划费用与院所成本另算。第 26 周加成仍生效，下次周更新移除。
- 78 次周更新内不能重复立项。主动终止不会退款或缩短冷却。
- 分别测试战争、闭关、识字率降至不足 20%、交流费不足：下一次周更新终止交流。若核心计划周费仍可支付，研发计划继续。
- 主动暂停科研计划：交流修正立即撤销，恢复科研时不会自动重开已终止的交流。

## 加载、语言与存档

- 简体中文和英文均不能显示裸露的 `ri_`、`pm_ri_`、`building_ri_` 键或无效动态取值。
- 保存并重载后，计划等级、经验周数、重点及冷却不重置，也不额外扣筹建费用。
- 验证国家切换和革命。日志设置为不随玩家转移、不由革命继承；变量的具体引擎继承行为尚未实机验证。
- 若日志所在国家不再由玩家控制，周更新是否继续取决于游戏日志行为，本版本不宣称支持 AI 接管既有国家计划。
- 在用户数据 `logs/error.log` 中检查 `ri_` 相关未知字段、无效作用域、生产方式、图标和本地化错误。

离线检查记录见 `compatibility.json` 与 `evidence/bindings.json`。当前 `game_verified` 均为 `false`；完成以上流程后才能对具体游戏构建宣称可用。
