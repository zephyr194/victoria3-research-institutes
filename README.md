# 国家科研院所 · State Research Institutes

Victoria 3 原生脚本 Mod，版本 **0.1.0（实验版）**。为大学之外的政府科研投入提供建筑、国家计划与科技交流机制。独立于本仓库的驻军和雇佣兵 Mod。

## 已实现

- **国家科研院所**：政府建筑，每级 1,000 个岗位；消耗纸张与工具，按实际配员提供创新力。基础实验室每个满员等级提供 0.4 创新力；研究“经验主义”后可切换协作网络，提供 0.8 创新力。保留原版创新力投资上限。
- **三级国家计划**：在日志中筹建、升级或缩减。选择生产、军事或社会重点，提供该领域 +5% / +10% / +20% 研发速度。实际从国库扣款，并占用行政力。
- **科技交流与译介**：考察、翻译与国际通信经费转为 +25% 原版科技传播，持续 26 个付费周，并占用 25 影响力。需要和平、非闭关政策与 20% 识字率。
- **运行管理**：可停拨与恢复；人员或黄金储备不足时停止国家计划扣费及加成，恢复后自动重新评估。交流中断后须另行立项，冷却不会重置。
- 简体中文与英文；使用原生日志、按钮、建筑及生产方式面板。

国家计划目前由玩家操作，按钮 AI 权重及科研院所建设 AI 值为 0。科技交流是国家交流政策，不含指定伙伴、双边条约或指定科技转让。研发重点强化原版科技树中对应领域的研究，不新增并行科技队列。

## 安装与开始

分别提供 1.13 与 1.14 目标安装包，位于 `dist/`。**两包选一个**，把包中的 `ri_research_institutes.mod` 和 `ri_research_institutes/` 解压至用户的 `Victoria 3/mod/`，在启动器中加入并启用。不要放入游戏本体目录。

先建造“国家科研院所”，等雇员达到编制 50%，再在“国家科研计划”日志中花费 £25,000 筹建。下一次周更新开始核定专项拨款。详情见 [安装与实机验收](docs/INSTALL_TEST.zh-CN.md)。

## 开发与检查

Python 3.10+，无第三方依赖。在本目录运行：

```sh
python3 tools/generate.py
python3 tools/validate.py
python3 -m unittest discover -s tests -v
python3 scripts/package.py --target 1.13 --experimental
python3 scripts/package.py --target 1.14 --experimental
```

如有本地游戏文件，可额外核对原版引用：

```sh
python3 tools/validate.py --game-dir "/path/to/Victoria 3/game"
```

当前通过离线结构、引用、脚本行为和归档检查，**未进行游戏引擎加载、画面或存档验证**。1.13 接口证据来自 1.13.11；1.14 来自 1.14.5-openbeta，安装包中的目标版本声明不是实机兼容认证。测试解释器不等同于游戏引擎。
